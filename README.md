# TeemoBOT

O TeemoBOT é um bot de Discord independente com economia por servidor, recompensas diárias, banco, loja, inventário, ranking local, comandos de diversão e moderação.

O site do projeto fica em:
https://pixelbarz.github.io/TeemoBOTSITE/

## O que tem no site

- **Início** — uma visão geral do bot e de como a economia funciona.
- **O bot** — o que já está disponível hoje, com valores e limites.
- **Comandos** — o manual completo, com busca e filtro por categoria.
- **Criador** — quem está por trás do projeto.
- **Privacidade** — quais dados o bot usa e como exercer seus direitos.

O convite público ainda não foi publicado. Quando estiver pronto, ele aparece no site.

## Sobre o projeto

O TeemoBOT é um projeto de fã, não oficial, feito por PixelBarz de forma independente. Foi criado sob a política “Legal Jibber Jabber” da Riot Games, usando ativos de propriedade da Riot apenas como referência visual. A Riot Games não endossa nem patrocina o projeto.

League of Legends e Teemo são marcas da Riot Games. As artes oficiais usadas no site pertencem à Riot Games e aparecem apenas como referência visual, com crédito. O projeto é de fã, sem fins comerciais.
